# kkqq9320 Home Assistant Apps

[한국어](README.ko.md)

Home Assistant apps (add-ons) by kkqq9320. The apps install as prebuilt images. Each app's code, tests and documents live in its own repository, listed below.

## Add the repository

Open [this link](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fkkqq9320%2Fha-apps), or go to **Settings → Apps → Install app**, open the **⋮** menu, choose **Repositories** and add `https://github.com/kkqq9320/ha-apps`.

## Apps

| App | Description | Repository |
|---|---|---|
| LG U+ Multitap (MTTL-W01) | Runs Tuo's standalone backend so LG U+ MTTL-W01 power strips connect to Home Assistant on your own network | [kkqq9320/ha-lgu-mttl-w01](https://github.com/kkqq9320/ha-lgu-mttl-w01) |
